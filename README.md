# Lumora Photography Studio

Lumora Photography Studio is a modern and responsive photography website designed for a professional photography studio. It features an elegant layout, photography portfolio, services, packages, testimonials, and an interactive booking section.

## Features

* Responsive photography studio website
* Modern and elegant user interface
* Hero section with studio introduction
* About the studio section
* Photography services
* Filterable portfolio gallery
* Photography packages and pricing
* Photographer profile
* Client testimonials
* Photography process section
* Interactive booking form
* Mobile responsive navigation
* Smooth scrolling
* JavaScript-based interactions

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/yourusername/lumora-photography.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation or build process is required.

## Purpose

This project was created as a frontend development portfolio project to practice responsive layouts, modern UI design, Tailwind CSS, image galleries, JavaScript interactions, and form handling.
